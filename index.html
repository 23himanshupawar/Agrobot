Chapter 1

Introduction

Overview, motivation, need for the system, and scope of the AgroBot project.

Abstract

The project "AGROBOT" focuses on the design and development of a semi-automated, multipurpose agricultural rover intended to assist farmers in precision farming practices. The system integrates an ESP32 microcontroller to coordinate various modules, including DC gear motors for mobility and sensors such as soil moisture, DHT, and LDR for environmental monitoring. The rover is remotely operated through Blynk, allowing real-time data collection. The soil moisture sensor is mounted on a servo mechanism for root-zone accuracy.

For plant health monitoring, a smartphone mounted on the rover uses its camera and processing capability to run an AI-based YOLOv8 model (TensorFlow Lite) for detecting plant diseases. The current implementation focuses on tomato cultivation as a representative use case. Additionally, the rover includes a pesticide spraying mechanism manually controlled via the application. This project demonstrates a practical and cost-effective approach toward integrating robotics and AI in agriculture.

💡

Motivation

Agriculture faces challenges including labour shortages, inefficient traditional practices, and lack of real-time soil and crop monitoring. These lead to improper resource utilization, reduced productivity, and increased vulnerability to crop diseases. Conventional methods rely on manual inspection and experience-based decisions — time-consuming, less accurate, and costly. There is a need for an integrated, user-friendly system that assists farmers in monitoring conditions and understanding crop health without completely replacing human decision-making.

🎯

Need of the System

Farmers must make timely decisions regarding irrigation, crop health, and pest control — still based on manual observation. Parameters like soil moisture vary across field locations, but traditional methods don't provide real-time or location-specific data. Early plant disease detection is difficult without tools, resulting in crop loss. Many technological solutions are either too complex, expensive, or focused on a single function. AgroBot provides a mobile, sensor-based, AI-assisted solution addressing all these needs.

Chapter 3 & 4

Objectives, Design & Methodology

Problem statement, system objectives, hardware/software design, and the complete system algorithm.

⚠️

Problem Statement

Agriculture in rural and semi-urban regions faces limited access to affordable technology, shortage of skilled labour, and dependence on manual monitoring. Farmers rely on visual inspection for soil and crop health, which is time-consuming and inaccurate — especially for plant diseases where delayed identification leads to crop loss. Existing smart farming solutions are costly, complex, or limited to single functionalities without an integrated platform.

🏗

System Architecture

A hybrid intelligent architecture: ESP32 manages hardware operations and communicates via Blynk. The Flutter/Dart mobile app provides navigation, sensor visualization, and AI results. A mounted smartphone runs OpenCV preprocessing + YOLOv8/TFLite disease detection focused on tomato leaf diseases. PCA9685 PWM driver provides precise servo control via I2C.

Hardware & Software Design

🔧 Hardware Components

⚡ ESP32 — Dual-core Tensilica LX6, 240 MHz, 520KB SRAM, Wi-Fi+BT
💧 Soil Moisture Sensor — Capacitive, 3.3–5V, corrosion-resistant
🌡 DHT Sensor — Temp (0–50°C) & Humidity (20–90% RH)
☀️ LDR Sensor — Ambient light / day-night detection
⚙️ Servo Motor (×2) — 4.8–6V, 0–180°, PWM via PCA9685
🎛 PCA9685 — 16-ch 12-bit PWM servo driver, I2C
🔌 Dual Channel Relay (×2) — Motor & pump switching
🚗 DC Geared Motors (4×) — 60 RPM, 6–12V, high-torque
💦 DC Water Pump — 5–12V, pesticide sprayer
🔋 Lead Acid Battery — Portable field operation
🏗 PVC Pipe Chassis — Lightweight, corrosion-resistant frame

💻 Software Stack

📟 Embedded C/C++ (Arduino IDE) — ESP32 firmware
📱 Flutter & Dart — Cross-platform mobile application
🌐 Blynk IoT — Bidirectional Wi-Fi communication platform
🔍 OpenCV — Image preprocessing (resize, normalize)
🧠 YOLOv8 — Object detection model for plant disease
⚡ TensorFlow Lite — On-device AI inference optimization
📊 Roboflow — Dataset collection & processing pipeline
🔗 I2C Protocol — ESP32 ↔ PCA9685 servo communication
Complexity Analysis
ESP32 embedded ops: O(1) — constant time per loop cycle
PCA9685 & relay control: O(1) — fixed operations
AI disease detection: O(n) — linear with image pixel count

Chapter 6.2

Future Scope

Planned enhancements to evolve AgroBot into a complete, enterprise-grade smart farming ecosystem.

Development Roadmap

What Comes Next

These enhancements directly address the current limitations and will dramatically expand AgroBot's capabilities and impact.

🛰 Autonomous Navigation with GPS

Implementation of fully autonomous path planning using GPS modules for complete field coverage without manual control. The rover will follow pre-programmed waypoint routes, ensuring systematic and repeatable field scans.

🧠 Advanced AI Models — Multi-Crop Support

Integration of more advanced architectures (EfficientNet, improved YOLOv8 versions) for higher accuracy across multiple crop types beyond tomatoes. Expansion of Roboflow dataset to support wider disease classifications.

☁️ Cloud Integration & Analytics Dashboard

Use of cloud platforms for large-scale data storage, long-term analytics, seasonal trend analysis, and yield prediction models. Web-based farmer dashboard for multi-field management.

💧 Automated Irrigation Control

Direct integration of irrigation valve control — the system will independently open/close based on soil moisture threshold readings, eliminating manual watering decisions entirely.

☀️ Solar Power Integration

Incorporation of solar panels for sustainable, energy-efficient operation. Eliminates battery dependency for daytime field operations and enables longer autonomous run times.

🏗 Improved Hardware Design

Development of a more robust, weather-resistant chassis with IP-rated enclosures for electronics, improved wheel traction for wet/muddy field conditions, and modular component mounting.

📈 Scalability — Multi-Robot Deployment

Enhancing the system to support large-scale farms with multiple AgroBot units, centralized control dashboard, and fleet management capabilities for coordinated field monitoring.

🌍 Long-Term Vision

AgroBot's long-term goal is to become a complete smart farming ecosystem — scalable, affordable, and AI-driven — that empowers millions of Indian farmers with higher yields, fewer inputs, and reduced environmental impact. By making precision agriculture accessible to smallholders through a sub-₹15,000 solution, AgroBot aims to contribute directly to India's agricultural transformation and food security goals.

Chapter 6.1

Conclusion

Summary of AgroBot's achievements, contributions, and significance for smart agriculture.

Project Conclusion

The AgroBot system successfully demonstrates the design and implementation of a smart, AI-integrated agricultural robot aimed at improving efficiency and decision-making in farming. The project effectively combines embedded systems (ESP32), IoT-based communication (Blynk), and artificial intelligence (YOLOv8 + TFLite) to create a multi-functional platform capable of monitoring soil conditions, analyzing crop health through computer vision, and assisting farmers through a mobile application interface.

The system performed real-time sensing of soil moisture, temperature, humidity, and light intensity, while enabling precise root-zone measurement using the servo-based PCA9685 mechanism. Relay-based motor control ensured reliable movement, and the spraying mechanism provided controlled pesticide application. The smartphone-based AI module successfully detected tomato plant diseases. All 47 integrated test cases passed, confirming reliable and stable system operation.
